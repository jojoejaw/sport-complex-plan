# 📌 สรุปขอบเขตของระบบ (สำหรับเสนออาจารย์ที่ปรึกษา)
## ระบบจองและจัดการสนามกีฬา (Sport Complex Booking System)

### 🛠️ ฟีเจอร์ที่ระบบรองรับ (Scope of Features)

1. **ระบบจัดการผู้ใช้และสิทธิ์การใช้งาน (Authentication & Roles)**
   * สมัครสมาชิก / เข้าสู่ระบบด้วย Username & Password
   * การแบ่งสิทธิ์ตามบทบาท: **ผู้ใช้งานทั่วไป (Customer)** และ **ผู้ดูแลระบบ (Admin)**

2. **ระบบค้นหาและเช็กรอบเวลาว่าง (Court Browsing & Real-time Slots)**
   * กรองสนามตามประเภทกีฬา (ฟุตบอล, บาสเกตบอล, แบดมินตัน, วอลเลย์บอล)
   * แสดงตารางสล็อตเวลา Real-time (10:00–22:00 น.) จำแนกสถานะด้วยสี (🟢ว่าง / 🔴จองแล้ว / 🟠รอชำระเงิน / ⚪เวลาผ่านไปแล้ว)
   * รองรับการเลือกจองต่อเนื่องสูงสุด 3 ชั่วโมง/ครั้ง

3. **ระบบการจองและล็อกสนามชั่วคราว (Booking & Time-Lock)**
   * ขั้นตอนการจอง 3 สเต็ป (เลือกเวลา -> ระบุเบอร์ติดต่อ -> ชำระเงิน)
   * ระบบ Countdown ล็อกสนาม 15 นาทีระหว่างโอนเงิน (หากเกินเวลาจะยกเลิกและคืนสนามว่างอัตโนมัติ)
   * หน้าประวัติการจองของผู้ใช้ (My Bookings) พร้อมแสดงตั๋วใบจองดิจิทัล

4. **ระบบชำระเงินและตรวจสลิปอัตโนมัติ (Payment & Real-time Verification)**
   * สแกนจ่ายผ่าน PromptPay QR Code ที่เจนยอดเงินตามจริง
   * ระบบสแกนตรวจสลิปโอนเงินอัตโนมัติ Real-time (Thunder API) เช็กยอด/บัญชี/เวลาอนุมัติการจองทันทีโดยไม่ต้องรอแอดมิน

5. **ระบบผู้ดูแลระบบ (Admin Dashboard & Management)**
   * **Analytics Dashboard:** สรุปยอดจอง, รายได้, กราฟแนวโน้มรายได้ และแผนภูมิสัดส่วนกีฬา (กรอง รายวัน/รายเดือน/รายปี/รวม)
   * **Booking Management:** ค้นหา คัดกรอง และปุ่ม **"อนุมัติรับเงินสด"** สำหรับลูกค้า Walk-in หน้าร้าน
   * **Court Management:** เพิ่ม/แก้ไข/ลบสนาม และสลับสถานะ **"ปิดปรับปรุงชั่วคราว"** เพื่อบล็อกการจองฝั่งลูกค้าทันที
