# 🛡️ คู่มือผู้ดูแลระบบ (Admin Manual)
## ระบบจองและจัดการสนามกีฬา (Sport Complex Booking System)

คู่มือฉบับนี้จัดทำขึ้นสำหรับ **ผู้ดูแลระบบ (Admin)** เพื่ออธิบายขั้นตอนการเข้าถึงแผงควบคุม การดูสถิติและรายได้ การอนุมัติการรับเงินสดหน้าร้าน การยกเลิกรายการจอง และการบริหารจัดการสนาม

---

## 🔑 1. การเข้าสู่ระบบผู้ดูแลระบบ (Admin Access)

1. เข้าสู่ระบบด้วย บัญชีผู้ใช้ที่มีบทบาทเป็น **Admin** (เช่น Username: `admin` / Password: `admin1234`)
2. เมื่อเข้าสู่ระบบสำเร็จ จะปรากฏปุ่ม **"แอดมิน"** พร้อมไอคอนโล่สีส้มบนแถบเมนูหลัก (Navbar)
3. กดที่ปุ่ม **"แอดมิน"** หรือเข้า URL `/admin` เพื่อเปิดแผงควบคุมระบบผู้ดูแลระบบ

---

## 📊 2. ภาพรวมระบบและแดชบอร์ด (Dashboard Overview)

เมื่อเปิดหน้า Admin แผงควบคุมจะแสดงเมนูด้านซ้ายและสถิติหลักในหน้าแรก:

### 2.1 การกรองช่วงเวลาข้อมูล (Period Filter)
ที่มุมขวาบนของแดชบอร์ด สามารถเลือกสลับช่วงเวลาการคำนวณสถิติได้ 4 รูปแบบ:
* **สรุปผลรวม (Total):** คำนวณยอดสะสมทั้งหมดตั้งแต่เปิดระบบ
* **รายวัน (Daily):** คำนวณสถิติเฉพาะของวันนี้ (อิงเขตเวลาประเทศไทย Asia/Bangkok)
* **รายเดือน (Monthly):** คำนวณสถิติเฉพาะของเดือนปัจจุบัน
* **รายปี (Yearly):** คำนวณสถิติเฉพาะของปีปัจจุบัน

### 2.2 การ์ดสรุปตัวเลขสำคัญ (KPI Summary Cards)
1. **การจองทั้งหมด:** จำนวนรายการจองที่เกิดขึ้นในช่วงเวลาที่เลือก
2. **รายการจองที่ยกเลิก:** จำนวนรายการจองที่ถูกยกเลิก (ทั้งจากระบบตัดหมดอายุ 15 นาที ลูกค้ากดยกเลิก หรือแอดมินยกเลิก)
3. **รอชำระเงิน:** จำนวนรายการที่อยู่ระหว่างรอโอนเงิน
4. **รับชำระแล้ว:** จำนวนรายการที่ชำระเงินสำเร็จและอนุมัติแล้ว
5. **รายได้รับ:** รวมยอดเงินรายได้ทั้งหมดจากรายการที่ชำระสำเร็จ/อนุมัติแล้ว

### 2.3 กราฟและแผนภูมิวิเคราะห์ (Analytics Charts)
* **กราฟเส้นรายรับ (Revenue Chart):** แสดงแนวโน้มรายได้ตามช่วงเวลา พร้อมฟังก์ชันชี้จุดเพื่อดูยอดเงิน
* **แผนภูมิวงแหวนสัดส่วนกีฬา (Sport Distribution Donut Chart):** แสดงเปอร์เซ็นต์และจำนวนครั้งการจองแยกตามประเภทกีฬา (ฟุตบอล, แบดมินตัน, บาสเกตบอล, วอลเลย์บอล)

## 🎟️ 3. การจัดการรายการจอง (Booking Management)

คลิกที่เมนู **"รายการจอง"** บนแถบเมนูด้านซ้าย เพื่อจัดการใบจองทั้งหมดในระบบ:

### 3.1 การค้นหาและกรองข้อมูล
* **ช่องค้นหา (Search):** สามารถพิมพ์ค้นหาด้วย Booking ID (เช่น `45`), ชื่อผู้ใช้ลูกค้า หรือชื่อสนามได้
* **ตัวกรองสถานะ (Status Filter):** เลือกกรองดูเฉพาะสถานะ `ทุกสถานะ`, `รอชำระเงิน`, `อนุมัติแล้ว`, หรือ `ยกเลิก`

### 3.2 การอนุมัติการรับเงินสดหน้าร้าน (Cash Payment Approval)
ในกรณีที่ลูกค้า walk-in มาชำระเงินสดที่เคาน์เตอร์หน้าร้าน:
1. คลิกที่แถบรายการจองของลูกค้ารายนั้นเพื่อเปิดหน้าต่างรายละเอียด (`AdminBookingManagementModal`)
2. ตรวจสอบข้อมูลสนาม วันที่ เวลา และยอดเงินที่ต้องชำระ
3. กดปุ่ม **"อนุมัติรับเงินสด"**
4. ระบบจะทำการบันทึกประวัติการชำระเงินลงตาราง `payments` (ระบุวิธีชำระเป็น `cash` และผู้รับเงินเป็น ID ของแอดมิน) และเปลี่ยนสถานะรายการจองเป็น `approved` ทันทีภายใน Transaction เดียว

### 3.3 การยกเลิกรายการจองโดยแอดมิน
1. คลิกที่รายการจองที่ต้องการยกเลิก
2. กดปุ่ม **"ยกเลิกรายการ"**
3. ยืนยันการยกเลิก ระบบจะเปลี่ยนสถานะเป็น `cancelled` และปลดล็อกสนามคืนสู่ระบบทันที

## 🏟️ 4. การจัดการสนามกีฬา (Court Management)

คลิกที่เมนู **"จัดการสนาม"** บนแถบเมนูด้านซ้าย เพื่อบริหารจัดการข้อมูลสนาม:

### 4.1 การเพิ่มสนามใหม่ (Create Court)
1. กดปุ่ม **"เพิ่มสนามใหม่"** มุมขวาบน
2. กรอกข้อมูลสนาม:
   * **ชื่อสนาม:** เช่น `สนามฟุตบอล C`
   * **ประเภทกีฬา:** เลือกประเภทกีฬาจากรายการ
   * **ราคา / ชั่วโมง:** กรอกตัวเลขราคาต่อชั่วโมง (เช่น `600`)
   * **URL รูปสนาม:** วางลิงก์รูปภาพสนาม (หากไม่ใส่จะใช้ภาพพื้นหลังระบบแทน)
   * **รายละเอียด:** กรอกคำอธิบายเพิ่มเติมเกี่ยวกับสนาม
3. กดปุ่ม **"บันทึกข้อมูล"**

### 4.2 การแก้ไขข้อมูลสนาม (Edit Court)
1. ที่การ์ดสนามที่ต้องการแก้ไข กดปุ่ม **"แก้ไข"**
2. ปรับเปลี่ยนข้อมูลที่ต้องการ แล้วกดปุ่ม **"บันทึกข้อมูล"**

### 4.3 การเปิด / ปิดปรับปรุงสนามชั่วคราว (Toggle Maintenance Status)
* ที่การ์ดสนาม กดปุ่ม **"ปิดปรับปรุงชั่วคราว"** หรือ **"เปิดให้บริการ"**
* สนามที่มีสถานะเป็น `maintenance` จะแสดงป้ายเตือนปิดปรับปรุงบนหน้าเว็บฝั่งลูกค้า และลูกค้าจะไม่สามารถกดจองสนามนั้นได้

### 4.4 การลบสนาม (Delete Court)
* ที่การ์ดสนาม กดปุ่ม **"ลบ"**
* ⚠️ **ข้อควรระวัง:** สนามที่มีประวัติการจองอยู่ในระบบจะไม่สามารถลบได้ (เนื่องจากมี Foreign Key อ้างอิง) แนะนำให้เปลี่ยนสถานะเป็น **"ปิดปรับปรุงชั่วคราว"** แทน
