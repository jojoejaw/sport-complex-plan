# 📌 เอกสารรายงานภาพรวมโครงงาน (Project Overview)
## ระบบจองและจัดการสนามกีฬา (Sport Complex Booking System)

---

### 1. ปัญหาที่ต้องการแก้ไข (Problem Statement)

1. **การจองสนามกีฬาแบบดั้งเดิมขาดประสิทธิภาพ:**
   - การเปิดรับจองผ่านสมุดบันทึก กระดาษ โทรศัพท์ หรือข้อความแชท ทำให้เกิดปัญหาตารางเวลาทับซ้อน (Double Booking) ข้อมูลคลาดเคลื่อน และผู้ใช้ต้องเสียเวลาติดต่อสอบถามเจ้าหน้าที่เพื่อเช็กสนามว่าง
2. **ความล่าช้าและความเสี่ยงในการตรวจสอบการชำระเงิน:**
   - การโอนเงินแล้วส่งสลิปให้เจ้าหน้าที่ตรวจสอบแบบ Manual ต้องใช้เวลาในการรอคอย อาจเกิดความผิดพลาดในการตรวจสอบยอดเงิน หรือเสี่ยงต่อการใช้สลิปปลอม/สลิปซ้ำ
3. **ขาดระบบล็อกสนามชั่วคราวขณะทำรายการ:**
   - ในช่วงเวลาที่ผู้ใช้กำลังดำเนินการโอนเงิน อาจมีผู้ใช้รายอื่นแทรกเข้ามาจองรอบเวลาเดียวกัน ส่งผลให้เกิดข้อขัดแย้งในการให้บริการ
4. **ความยุ่งยากในการติดตามสถานะของผู้ใช้:**
   - ผู้ใช้บริการไม่สามารถตรวจสอบสถานะใบจอง ยอดเงินที่ต้องชำระ หรือประวัติการใช้งานย้อนหลังได้อย่างสะดวกและ Real-time
5. **แอดมินขาดระบบบริหารจัดการและสรุปสถิติเชิงลึก:**
   - เจ้าหน้าที่สนามไม่มีระบบแดชบอร์ดสรุปรายได้ ประสิทธิภาพการใช้งานสนาม หรือสถิติตามประเภทกีฬา เพื่อนำไปวางแผนปรับปรุงบริการและบริหารจัดการสนาม (เช่น การตั้งค่าปิดปรับปรุงสนามชั่วคราว)

---

### 2. แนวทางแก้ไขของระบบ (System Solution)

1. **พัฒนา Web Application แบบ Full-Stack ตอบโจทย์ 24 ชั่วโมง:**
   - พัฒนาส่วนหน้าด้วย **React 19 + Vite + Tailwind CSS v4** และส่วนหลังด้วย **Node.js Express + MySQL** เพื่อให้ระบบรองรับการใช้งานผ่านเว็บเบราว์เซอร์ได้รวดเร็ว ปลอดภัย และแสดงผลแบบ Responsive บนทุกอุปกรณ์
2. **ตารางเวลาว่างและสล็อตสถานะ Real-time:**
   - แสดงตารางเวลาให้บริการ (10:00 - 22:00 น.) พร้อมสัญลักษณ์สถานะสล็อตเวลาชัดเจน (🟢 ว่าง / 🔴 จองแล้ว / 🟠 รอชำระเงิน / ⚪ เวลาผ่านไปแล้ว) ป้องกันการจองซ้ำ และรองรับการเลือกจองต่อเนื่องได้สูงสุด 3 ชั่วโมง
3. **ระบบล็อกสนามชั่วคราว 15 นาที (Countdown Hold):**
   - ล็อกรอบสนามให้ผู้ใช้ทันทีเป็นเวลา 15 นาทีอัตโนมัติขณะทำรายการชำระเงิน หากเกินเวลาโดยไม่อัปโหลดสลิประบบจะยกเลิกการจองและคืนสิทธิ์สนามว่างเข้าสู่ระบบทันที
4. **การชำระเงินออนไลน์และสแกนสลิปอัตโนมัติ (Automated Real-Time Slip Scan via Thunder API):**
   - สร้าง QR Code PromptPay ตามยอดจองจริงโดยอัตโนมัติ พร้อมระบบสแกนตรวจสอบสลิปโอนเงิน Real-time ที่เช็กยอดเงิน บัญชีผู้รับ และเวลาโอน เพื่ออนุมัติรายการจองทันทีโดยไม่ต้องรอเจ้าหน้าที่ตรวจ
5. **แผงควบคุมสำหรับผู้ดูแลระบบ (Admin Dashboard & Court Management):**
   - **สถิติ & Analytics:** แสดงสรุปยอดการจอง รายได้รับ กราฟแนวโน้มรายได้ และแผนภูมิสัดส่วนการใช้สนามตามประเภทกีฬา (สามารถเลือกกรอง รายวัน / รายเดือน / รายปี / ทั้งหมด)
   - **อนุมัติเงินสด (Walk-in Cash Payment):** รองรับผู้ใช้ที่มาชำระเงินสดหน้าร้านด้วยฟังก์ชันอนุมัติรับเงินสด บันทึกประวัติการชำระเงินลงตาราง `payments` และเปลี่ยนสถานะรายการจองทันทีภายใน Transaction เดียว
   - **บริหารจัดการสนาม:** สามารถเพิ่ม แก้ไข ลบสนาม และสลับสถานะ "ปิดปรับปรุงชั่วคราว" (Maintenance) เพื่อปิดกั้นการจองสนามนั้นๆ บนหน้าเว็บฝั่งผู้ใช้ทันที

### 3. กลุ่มผู้ใช้งานเป้าหมาย (Target Users)

1. **ลูกค้า / ผู้ใช้บริการทั่วไป (Customers / End-Users):**
   - **กลุ่มเป้าหมาย:** นักศึกษา, บุคลากร, และบุคคลภายนอกที่ต้องการใช้งานสนามกีฬา
   - **ลักษณะการใช้งาน:** ค้นหาสนามตามประเภทกีฬา (ฟุตบอล, บาสเกตบอล, แบดมินตัน, วอลเลย์บอล), เช็กสล็อตเวลาว่าง, จองสนามออนไลน์, ชำระเงินผ่าน PromptPay QR Code, อัปโหลดสลิป และตรวจสอบตั๋ว/ประวัติการจองของตนเอง
2. **ผู้ดูแลระบบและเจ้าหน้าที่สนาม (Admins / Complex Staff):**
   - **กลุ่มเป้าหมาย:** เจ้าหน้าที่บริหารจัดการศูนย์กีฬา และผู้ดูแลระบบคอมพิวเตอร์
   - **ลักษณะการใช้งาน:** ตรวจสอบและอนุมัติการรับเงินสดหน้าร้าน (Walk-in), จัดการข้อมูลสนามและประเภทกีฬา, ตั้งค่าสนามปิดปรับปรุงชั่วคราว, ยกเลิกรายการจองกรณีพิเศษ และติดตามแดชบอร์ดสรุปรายได้กับสถิติภาพรวม
