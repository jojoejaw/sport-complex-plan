# 📌 สรุปภาพรวมโครงงาน (สำหรับเสนออาจารย์ที่ปรึกษา)
## ระบบจองและจัดการสนามกีฬา (Sport Complex Booking System)

### 🎯 1. ปัญหาที่ต้องการแก้ไข (Problem)
* **การจองแบบเดิมซ้ำซ้อน:** ใช้กระดาษ/โทรศัพท์ ทำให้เกิดปัญหาจองเวลาชนกัน (Double Booking) และผู้ใช้ต้องคอยสอบถามเจ้าหน้าที่ว่าสนามว่างหรือไม่
* **การตรวจสอบชำระเงินล่าช้า:** แอดมินต้องตรวจสลิปแบบ Manual ทำให้ผู้ใช้ต้องรออนุมัตินาน และไม่มีระบบล็อกสนามชั่วคราวขณะโอนเงิน
* **ขาดระบบสรุปข้อมูล:** แอดมินไม่มีแดชบอร์ดดูสถิติการใช้งานและรายได้จริง

---

### 💡 2. แนวทางแก้ไขของระบบ (Solution)
* **เว็บแอปพลิเคชันจองสนาม 24 ชม.:** (React + Express + MySQL) ให้ผู้ใช้เช็กสล็อตเวลาว่าง (10:00-22:00 น.) และกดจองออนไลน์ได้ทันที
* **ล็อกสนามชั่วคราว 15 นาที:** ล็อกสิทธิ์ระหว่างโอนเงินอัตโนมัติ ป้องกันผู้อื่นจองตัดหน้า
* **สแกนตรวจสลิปอัตโนมัติ:** จ้างจ่ายผ่าน PromptPay QR Code และใช้ API ตรวจสลิป Real-time เพื่ออนุมัติการจองทันทีโดยไม่ต้องรอแอดมิน
* **ระบบแอดมินครบวงจร:** อนุมัติรับเงินสดหน้าร้าน (Walk-in), จัดการเปิด/ปิดปรับปรุงสนาม และมีแดชบอร์ดสรุปรายได้/สถิติตามประเภทกีฬา

---

### 👥 3. กลุ่มผู้ใช้งานเป้าหมาย (Target Users)
1. **ผู้ใช้บริการทั่วไป (นักศึกษา / บุคลากร / บุคคลภายนอก):** เช็กรอบเวลาว่าง จองสนาม จ่ายเงินออนไลน์ และดูตั๋ว/ประวัติการจอง
2. **ผู้ดูแลระบบ (เจ้าหน้าที่สนาม / แอดมิน):** ดูแดชบอร์ดสถิติ อนุมัติเงินสดหน้าร้าน และบริหารจัดการข้อมูลสนาม
